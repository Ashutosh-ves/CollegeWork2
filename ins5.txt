5. Create a simple web application, create a Dockerfile for the application, build a Docker image, and run a container to serve the web application.

To take your Docker skills to the next level, we will move away from pre-built static servers and build a custom backend application from scratch. 

We will create a simple **Node.js and Express** web application, containerize it, and run it. The best part about this process is that you don't even need Node.js installed on your local computer—Docker handles all the dependencies inside the container!

Here is the complete process.

---

### Step 1: Create the Web Application

First, we need to write the actual application code. We will keep it to just two files to make it simple.

1.  **Create a new project folder and navigate into it:**
    ```bash
    mkdir my-node-app
    cd my-node-app
    ```
2.  **Create the `package.json` file:** This file tells Node.js what dependencies your app needs (in this case, just the Express framework).
    ```bash
    nano package.json
    ```
    *Paste the following code, save, and exit:*
    ```json
    {
      "name": "docker-node-app",
      "version": "1.0.0",
      "description": "A simple web app for Docker testing",
      "main": "app.js",
      "dependencies": {
        "express": "^4.18.2"
      }
    }
    ```
3.  **Create the application code (`app.js`):**
    This file creates a basic web server that listens on port 3000.
    ```bash
    nano app.js
    ```
    *Paste the following code, save, and exit:*
    ```javascript
    const express = require('express');
    const app = express();
    const port = 3000;

    app.get('/', (req, res) => {
      res.send('<h2>Success! Your Node.js App is running inside a Docker Container!</h2>');
    });

    app.listen(port, () => {
      console.log(`App running on http://localhost:${port}`);
    });
    ```

---

### Step 2: Create the Dockerfile

Now that we have an application, we need to give Docker the instructions on how to build an environment for it.

1.  **Create the `Dockerfile`:**
    ```bash
    nano Dockerfile
    ```
2.  **Add the build instructions:**
    *Paste the following configuration. Read the comments to understand what each line does:*
    ```dockerfile
    # 1. Use the official lightweight Node.js image as the base
    FROM node:18-alpine

    # 2. Set the working directory inside the container
    WORKDIR /usr/src/app

    # 3. Copy package.json to the working directory
    COPY package.json ./

    # 4. Install the application dependencies (Express)
    RUN npm install

    # 5. Copy the rest of your application code (app.js)
    COPY . .

    # 6. Expose the port the app runs on
    EXPOSE 3000

    # 7. Define the command to start the application
    CMD ["node", "app.js"]
    ```
    *(Save and exit)*

---

### Step 3: Build the Docker Image

With your application files and Dockerfile ready, it is time to package them into an image.

1.  **Run the build command:**
    Ensure you are in the `my-node-app` directory where the Dockerfile is located. We will tag (`-t`) the image as `custom-node-app`.
    ```bash
    docker build -t custom-node-app .
    ```
    *Docker will download the Node.js base image, copy your files, and run `npm install` inside the image to set everything up.*

2.  **Verify the image was created:**
    ```bash
    docker images
    ```
    *You should see `custom-node-app` in the list.*

---

### Step 4: Run the Container

Now we will start a container using your newly minted image.

1.  **Start the application container:**
    We will run it in detached mode (`-d`) and map your computer's port 3000 to the container's internal port 3000 (`-p 3000:3000`).
    ```bash
    docker run -d -p 3000:3000 --name node-server custom-node-app
    ```
2.  **Verify the container is running:**
    ```bash
    docker ps
    ```
    *You should see `node-server` up and running, exposing port 3000.*

3.  **Check the application logs (Optional):**
    If you want to see the `console.log` output from your `app.js` file, you can peek inside the container's logs:
    ```bash
    docker logs node-server
    ```
    *It should output: `App running on http://localhost:3000`.*

---

### Step 5: Test the Web Application

1.  Open your web browser.
2.  Navigate to:
    ```text
    http://localhost:3000
    ```
    *(If you are running this on an EC2 instance instead of your local computer, use `http://<your-ec2-public-ip>:3000` and ensure Port 3000 is open in your AWS Security Group).*

You will see the success message generated by your custom Node.js backend. You have successfully written, containerized, and deployed a custom application!
